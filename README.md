# POSEIDON · THIRIO · EA24 → GΠ

Μονοσέλιδο site για τον πλανήτη Ποσειδώνα, στην ίδια λογική με το site της Αφροδίτης:

- **ίδιο UI / ίδια ροή** επιλογής Στίγματος Α και Β
- **EA24 → GΠ** εσωτερικό σύστημα
- **Ομφαλός = Το Θηρίο / Ποσειδών**
- **H=0** ακριβώς στο Θηρίο
- witness της λέξης **ΠΟΣΕΙΔΩΝ → 149 → 1260 - 149 = 1111 = ΙΩΤΑ**
- ενδεικτικά markers **Voyager 2 radio occultation** για validation UI

## Περιεχόμενα

- `index.html` — το site
- `.github/workflows/build_poseidon_tiles.yml` — GitHub Action για παραγωγή synthetic θαλασσί tile pyramid

## Tile strategy

Επειδή εδώ δεν χρησιμοποιείται χαρτογραφημένο body-fixed φωτομωσαϊκό όπως στην Αφροδίτη, το workflow παράγει **synthetic sea-blue tiles** σε τοπικό εσωτερικό frame:

- frame: `POSEIDON_LOCAL_OMPHALOS_H0`
- domain: `[-180,+180]` signed internal longitude
- 2x1 tile layout στο z0
- z0..z5 pyramid

Το υπόβαθρο είναι **καλλιτεχνικό** και δεν ορίζει ούτε μετακινεί την αγκύρωση.
